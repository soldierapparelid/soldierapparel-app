# Separate fixed lifecycle Google assembly

SOURCE OFF; no main HTML or live division endpoint is installed. The earlier nine-module pure and six-module append runtime builds remain unchanged. This separate offline builder assembles twenty-eight exact reviewed modules plus the pinned Utilities primitives. It includes current-account verification, bounded decoded Google responses, fixed-root REST, the compatible lifecycle and finance services, finite shared admission, scoped division and owner DTO codecs, and separate narrow RPC gateways. The dedicated owner gateway selects only the server's owner methods; current retained authority is still checked independently by the runtime.

Each module hash uses UTF-8 with CRLF normalized to LF. The primitive source has its own exact hash. Dependencies are explicit, ordered and checked once; unknown or remaining requires, unsupported runtime/host globals, symlinks, path escape and oversized source are rejected. There is no hash-update/override switch. Fixed graph auditing is conservative text scanning backed by exact hashes, not a general static security proof.

The assembly evaluates without touching Utilities, OAuth, network, database, locks or properties. Its default configuration is OFF with empty binding and disabled lanes. Internal factories receive reviewed host objects explicitly; they supply no public `doGet`, `doPost`, account configuration or credential route.
