📦 Katalog Produk Jadi

Klik SKU buat edit HPP & harga. Stok auto-sync dari laporan-produksi.

⚙️ Default HPP Overhead

Overhead = biaya operasional per pcs (packing, listrik, sewa, dll) yang di-alokasi ke setiap produk.

💸 Fee Marketplace & PPN

Fee auto-dipotong dari harga jual untuk hitung margin NET (yang beneran lo terima). Update sesuai program marketplace lo.
💡 Contoh Shopee retail Rp 120.000: Fee 6% + Ship 3% = 9% = Rp 10.800. PPN 11% dari harga = Rp 11.892. Net diterima = Rp 97.308.

🧷 Master Aplikasi (Resleting, Kancing, dll)

Simpan daftar aplikasi + harga jadi bisa cepet dipilih pas edit SKU.

🚀 Bulk Actions

Edit banyak SKU sekaligus per series.

🤖 Mode Auto vs Manual

Sekarang semua komponen HPP otomatis real-time dari command lain:
• HPP Bahan = kg per pcs × harga kain (dari tab Pembelian)
• Upah Potong = auto dari tarif master potong-command Setup
• Upah Jahit = auto rata-rata tarif dari jahit-command Assign tab
• Overhead = default global di atas (bisa override per SKU)

Kalau upah tarif di command lain berubah → HPP di sini langsung ikut update.
Kalau lo isi angka manual di modal edit SKU = override, ga ikut auto lagi.
