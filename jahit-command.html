Info Akses

Tool TOOL PERBAIKAN SINKRONISASI

Kalau data di HP beda sama laptop/PC, atau data balik-lagi setelah diedit, pake tool di bawah.
Ambil data terbaru tanpa membuang draf yang belum terkirim. Perubahan yang bertabrakan akan ditahan untuk diperiksa.
Jangan hapus cache ketika ada draf menunggu. Unduh cadangan sinkronisasi di bawah sebelum memulihkan data.

Sambung Sambungkan Firebase

Perhatian: HP ini belum tersambung Firebase (Offline).
Minta owner kirim config Firebase via WhatsApp, paste di sini, klik Sambungkan. Data auto masuk.
[Tip] Config = 3 baris teks dari owner. Setelah tersambung, kartu ini bakal hilang otomatis.

Terkunci Admin PIN (Wajib!)

Perhatian: WAJIB set PIN ini biar tukang GA BISA masuk mode Admin!
Tanpa PIN, tukang bisa klik "Ganti Mode -> Admin" dan liat semua data (tarif, kerjaan orang lain, dll).
[Tip] Kasih PIN ini cuma ke owner/admin lo aja, jangan kasih ke tukang.
Kalau PIN hilang, minta bantuan owner. Cadangkan dan selesaikan draf sinkronisasi sebelum mengubah penyimpanan perangkat.
